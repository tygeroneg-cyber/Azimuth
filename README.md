# Azimuth

Daily world and markets briefing, in English and Romanian. A new edition every morning at 08:45, Romania time.

Live: https://tygeroneg-cyber.github.io/Azimuth/

Developed by Sergiu-Pompei Pavel and Dragoș Petrișor Verzia.

## Working on the app

The app source is `src/template.html`. After changing it, rebuild `index.html`:

```
python3 scripts/build.py
```

See `CLAUDE.md` for the structure, the rules and how the daily editions are published.
